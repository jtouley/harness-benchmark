Add a CSV export to the CLI. `budgetcli export --month 2026-10` prints every expense of that month as CSV with the header `date,category,amount,note`, one row for each expense, oldest first. Amounts print with two decimals. A note with a comma, a quote or a newline is quoted as RFC 4180 says. `budgetcli export` with no `--month` prints every expense. `--out <file>` writes the CSV to that file instead of stdout and prints the row count. A wrong month is an `error:` line and exit 2, never a traceback. Ticket LOCAL-4. Later, ticket LOCAL-9 will upload this export to the bank portal. That upload waits on LOCAL-8, the portal API credentials, which are not issued yet, so the upload is not part of this change.
